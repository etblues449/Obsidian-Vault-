# 🔄 Recurring Tasks

Auto-generated project tasks based on project cadence. Copy templates into your weekly review to auto-populate tasks.

---

## 📺 Faceless Finance (Wed/Fri/Sun)

**Schedule:** Wed 4PM (priority), Fri, Sun

```
- [ ] Video idea brainstorm — Wed
- [ ] Research topic & script outline — Thu
- [ ] Film + edit — Fri
- [ ] Upload to YouTube — Fri evening
- [ ] Engage comments & analytics review — Sat/Sun
- [ ] Schedule next week's content — Sun
```

**Deadline tracking:** Videos due Wed 4PM, Fri 6PM, Sun 6PM

---

---

## 🛠 How to Use

1. Copy the task list for your project into that week's tasks (via Dataview or manual)
2. Check off as you go
3. Repeat weekly/monthly automatically (or use Templater to auto-insert)
4. Dataview will show completion rate in Projects Dashboard

## Work Forecasting
- [ ] [Monthly checkpoint if 1st-5th or 20th]
