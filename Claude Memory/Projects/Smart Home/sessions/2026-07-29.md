## Decision recorded this session

**ESPHome I²S is a mutex, not full duplex (2026-07-28).**
`I2SAudioMicrophone::start_driver_()` opens with
`if (!this->parent_->try_lock()) return false;` — only one direction can hold the bus.

**`timeout: never` on a speaker holds the bus forever and permanently blocks the
microphone.** It must be a real value (500ms). Nothing errors; the mic simply never starts.

Two consequences, architectural rather than tunable:
- **No barge-in.**
- **Continuous wake-word listening blocks non-conversational TTS.**
