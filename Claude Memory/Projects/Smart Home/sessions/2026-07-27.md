## Decisions

- **`webapp-reviewer` kept, not merged** into `jarvis-integration-qa` — ~15% overlap,
  but it is frozen to Carousel baseline `d8e5532` and read-only by design. Its
  `model: sonnet` departs from the harness `opus` standard; left as-is pending a call.
- **QA gets exactly one veto** — an unresolved S1 (silent-failure) blocks a commit.
  S2/S3 report only. Silent failures are the class that actually ships here.
- **QA has no Write/Edit tools by design.** A checker that repairs what it finds destroys
  the signal about which agent's process leaked the defect.
- **Two crons per skill are correct, not redundant.** Collapsing to one breaks half
  the year.

## Second pass — everything closed

- **Reconciled the project set.** `runner.mjs` and `test/local-test.mjs` both list five
  projects including `Work Financial Forecasting`; `CLAUDE.md` and
  `.claude/hooks/session-start.sh` listed four and pointed at the wrong
  `capture_queue.md`. The engine and its tests were authoritative, so both documents
  were corrected to match — 7 mandatory files became 8.
- **Created 7 dangling link targets**, not 6. Fixing the checker's link resolution
  exposed one more: `[[sessions/2026-06-19]]` had been silently resolving to
  `JARVIS/Inbox/Journal/2026-06-19.md`, an unrelated daily journal. Every stub carries
  only what the index itself recorded, with `<!-- TO FILL -->` elsewhere.
- **Fixed two checker bugs that pointed in opposite directions.** It false-PASSed
  path-scoped wikilinks via a global basename fallback, and false-FAILed links to real
  non-md files by blindly appending `.md`. Obsidian's actual rule now applies: a link
  containing a slash resolves as a path; only a bare name uses the vault-wide fallback.
- **Reclassified status claims as `REVIEW`.** Previously every `LIVE`/`DEPLOYED` string
  counted as a failed check, so the checker could never reach green and would have been
  ignored within a month. `REVIEW` means "a human must confirm this", distinct from
  `UNVERIFIED` which means "I tried and could not".
