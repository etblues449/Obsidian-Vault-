## Decisions

- v2 fronts the existing core over HTTP rather than rewriting jarvis-app.mjs blind —
  the core's newest code exists only on the Fold, so its HTTP surface is the safe
  contract; the UI's protocol layer is tolerant (SSE/NDJSON/JSON/text) and shows
  diagnostics on anything unexpected.
- Browser-TTS toggle defaults OFF (core already speaks on-device; avoids double audio).
- Phone-side always-on wake word **deliberately not shipped**: Samsung audio-focus
  conflict + Doze + online-STT dependency = the banned kind of workaround. £0 answers:
  side-key remap to the installed app now; ESPHome satellites for room wake (plan of
  record, Option B runbook already patched 2026-08-04).

## Blockers / not verified from here

- Live `/api/chat` event shapes unverifiable (private repo, 31 days stale) — mitigated
  by the tolerant parser + visible diagnostics; tested against a faithful mock only.
- On-device behaviour: **the open gate is the 5-minute smoke test** (tap icon → speak →
  reply → "thanks" ends it → reboot phone → icon works cold with Termux never opened).
