## What Was Built

Full phone-native implementation for Android 15 Termux (Claude Code v2.1.112):

### Components (7 files)
1. **jarvis.sh** — Main classifier + router
   - Text/voice input → Claude Haiku classification
   - Routes: note/task/idea/journal → Inbox files OR ha_action → HA REST
   - Auto-commits to git

2. **ha-call.sh** — Entity-safe HA REST wrapper
   - Calls HA services (turn_on/turn_off/set_temperature)
   - Known-broken entity skip logic
   - LAN-only v1; Tailscale documented for v2

3. **sync.sh** — Git orchestration with wake-lock
   - `git pull → add → commit → push` idempotent
   - Branch-aware (pushes current branch, not hardcoded master)
   - Runs from cron or manually

4. **digest.sh** — Daily summarization (cron @ 9 AM)
   - Reads Inbox files from last 24h
   - Claude Sonnet summarization
   - Writes to Journal/YYYY-MM-DD.md
   - termux-notification alert

5. **install.sh** — Idempotent one-time setup
   - Deps check/install (git, curl, termux-api, cronie)
   - Vault clone or in-place check
   - FUSE safety verification (rejects OneDrive)
   - ~/.jarvis/.env template creation
   - Cron + Termux:Widget shortcuts setup
   - Auto-detection of vault directory structure

6. **.env.example** — Secrets template (gitignored)
   - ANTHROPIC_API_KEY, HA_URL, HA_TOKEN
   - User copies to ~/.jarvis/.env and fills

7. **README.md** — User guide + troubleshooting
   - Quick start (install → edit secrets → test)
   - Widget usage
   - HA control examples
   - Cron scheduling
   - v2 roadmap

### SPEC.md
Full architecture document covering:

## Design Decisions Locked In

| Decision | Rationale |
|----------|-----------|
| Classifier: Haiku 4.5 | Cheap + fast for categorization |
| Conversation: Sonnet/Opus | Better quality for digest summarization |
| Secrets in ~/.jarvis/.env | v1 pragmatism; revisit Android Keystore in v2 |
| Vault in Termux FS only | FUSE (OneDrive) corrupts git; must use native /data/data |
| Voice loop + wake word = v2 | Battery/privacy risk; text + widget solid for v1 |
| HA v1 = LAN REST only | Simpler, more reliable; Tailscale documented but not bundled |
| Cron (cronie) not systemd-user | Termux has no systemd; cronie is Android-friendly |
