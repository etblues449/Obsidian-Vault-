## Phase 1 — hardline blocklist BUILT + TESTED, **NOT shipped**

The one real gap: **catastrophic commands are refused even if confirmed** — covering the
injection-talks-you-into-yes case and the fat-finger case. Checked *before* safe-mode and
*before* confirm, so there is no bypass.

- **Built:** `lib/hardline.mjs` — standalone, pure, zero-dep.
  `checkHardline(toolName, args)` → `{blocked, reason, matched}`. Recursively scans every
  string in the args tree. **19 patterns:** `rm -rf`, `Remove-Item -Recurse -Force`
  (order-free), `Format-Volume` / `format X:`, `mkfs`, `dd` to raw disk, redirect to
  `/dev/disk`, `Clear-Disk`, `Stop`/`Restart-Computer` + `shutdown`, fork bombs (POSIX
  and Windows), `curl|bash` / `iwr|iex`, `iex(`, reads of `.env`/`.ssh`/`id_rsa`/
  credentials/tokens, env dumps, `chmod -R 777 /`, disabling Defender.
- **Tested: 25/25 green** — 15 must-block, 8 must-allow, plus nested-args and empty-args.
- **Two real bugs found *by* the tests and fixed:** PowerShell flags needed order-free
  lookaheads, and a `\b` before `-Recurse` broke the match.
  **Do not reintroduce `\b` before a hyphenated flag.**

**Status is sandbox-only.** The file is not on the phone and `lib/agent.mjs` is unedited.
The current sandbox SHA (`ae0738511c…`) **must be recomputed at package time.**

**The pending edit** (shown to Jelly Bean, awaiting go) — one import beside the rails
import, and one guard block in `executeToolCall` placed **after**
`onToolUse?.({ name, args, gated })` and **before** `if (gated && isSafeMode())`:

```js
import { checkHardline } from './hardline.mjs'

// Hardline floor: catastrophic, irreversible commands refused even if confirmed.
const hard = checkHardline(tool.name, check.value)
if (hard.blocked) {
  audit({ tool: tool.name, decision: 'blocked-hardline', reason: hard.reason, args: summarise(check.value) })
  return (
    `BLOCKED — refused as a catastrophic action (${hard.reason}). This was NOT ` +
    `performed and cannot be, even with confirmation. Tell the user plainly what ` +
    `was refused and why. Never claim it happened.`
  )
}
```

Before `isSafeMode` deliberately: catastrophic actions are refused **even when safe mode
is off.**
