### Three delivery failures worth keeping (all caught by gates, zero damage)
1. **Corrupt base64.** I hand-transcribed the tar.gz base64 into the vault and mangled a repetitive
   run at char 7053. SHA gate refused to install. **Fix: stop shipping base64 for source.** Plain
   `.mjs` files in the vault round-trip exactly and are diffable. New packages live at
   `Assistant Core/packages/persona/*.mjs` fetched directly, each SHA-verified.
2. **Multi-line imports.** The patcher inserted the new import after "the last line matching
   `^import`" — in `heartbeat.mjs` that is `import {` of a multi-line block, so the import landed
   inside the braces. **Fix: insert BEFORE the first import** (imports hoist; the first is always a
   clean statement boundary). Fixtures now include a multi-line-import file.
3. **⚠️ SHA pinning proves integrity, NOT freshness.** After fixing #2 the phone failed identically.
   Cause: `raw.githubusercontent` edge served the phone a CACHED v1 of BOTH installer and patcher.
   Because the v1 installer pinned v1's SHA, the stale pair verified clean and the broken patcher
   ran. My sandbox hit a fresh edge, so it looked fine to me. **Fix: cache-bust every fetch**
   (`?cb=$(date +%s)$$` + no-cache headers) AND assert on file CONTENT (grep for the fix) before
   trusting it. This is a general trap for every future vault-delivered installer.
