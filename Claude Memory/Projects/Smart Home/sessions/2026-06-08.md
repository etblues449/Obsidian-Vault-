# 2026-06-08 — RuView CSI node fixed + WiFi sensing live on HA Green

## Outcome: DONE — WiFi-CSI presence/vitals pipeline permanent & phone-free

### What was broken → fixed
- **Node 3 (ESP32-S3, MAC e0:72:a1:e7:03:60) boot loop** — prebuilt `s3-adr110` bins shipped an 8MB partition table on a 4MB board (`ota_1` ran past flash end). Fixed by generating a valid 4MB partition table from `partitions_4mb.csv` (`gen_partition_4mb.py`) and reflashing: bootloader 0x0, table 0x8000, app 0x20000, `--flash-size 4MB`.
- Node now boots clean, WiFi STA, DHCP IP **192.168.0.227**, senses (presence/motion + breathing/heart-rate via CSI), streams 60-byte feature_state over UDP.

### Pipeline (final, permanent)
- **Receiver = local HA add-on "RuView CSI Bridge"** in `\\192.168.0.200\addons\ruview_bridge\` (config.yaml/Dockerfile/build.yaml/run.sh/bridge.py). `host_network: true` so UDP 5005 + HTTP 3000 bind on .200. Boot=auto + Watchdog. Built on HA base aarch64 + apk python3.
- **bridge.py** = merged UDP watcher + rvagent HTTP API (stdlib only, in-memory state). Endpoints: /health, /api/v1/sensing/latest, /vitals, /bfld/last_scan, /semantic-events, POST subscribe.
- **rvagent MCP** (@ruvnet/rvagent) in Claude Desktop config, env `RUVIEW_SENSING_SERVER_URL=http://192.168.0.200:3000`. Confirmed loading tools.
