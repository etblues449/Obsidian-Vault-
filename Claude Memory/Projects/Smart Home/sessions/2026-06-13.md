## Decisions from this session

- **Pin Claude Code to v2.1.112 and disable the auto-updater.** Every release from
  v2.1.113 onward pulls a 233 MB glibc native binary that Android kills mid-download.
  Disable in **both** places or it silently re-breaks itself:
  `DISABLE_AUTOUPDATER=1` in `~/.bashrc` **and** `"autoUpdates": false` in
  `~/.claude/settings.json`.
- **git MCP: use `uvx mcp-server-git`, not npx.** The npm version will not connect.
  Falling back to the `git` CLI is fine.
- **Interactive `read -s` token paste fails on mobile** — let `git` prompt for
  credentials instead.
