## Key learnings (durable)
- The npm install path for Claude Code is **dead on Termux from v2.1.113 onward** — it pulls a 233 MB glibc native binary that Android kills mid-download. The fix is to pin to **2.1.112** and disable the auto-updater, otherwise it silently re-breaks itself.
- Earlier crashes were caused by three things stacking: the 233 MB download under memory pressure, two concurrent Termux sessions, and a slow mirror. Reliable recipe = single session + wakelock + pinned version.
- The git MCP requires `uvx mcp-server-git`; do not try the npm package, it just hangs.
- Interactive `read -s` for token paste **does not work on mobile** — the keyboard swallows the next line. Let `git` prompt for credentials itself.
