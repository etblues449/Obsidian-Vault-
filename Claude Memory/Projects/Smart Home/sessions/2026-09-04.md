## Environment — three Termux failures on the S22

1. **Node was broken:** `CANNOT LINK EXECUTABLE "node": cannot locate symbol
   OSSL_PROVIDER_add_conf_parameter`. Misleading, because `pkg install nodejs` reports *"already
   the newest version (26.4.0-1)"* and changes nothing — the binary is present, its OpenSSL linkage
   is stale. **Fix: `pkg reinstall openssl nodejs`**, answering **N** at the `openssl.cnf` prompt.
   (`pkg upgrade` first aborted at 203 MB; the targeted reinstall was enough.)
2. **No pager:** `git log` fails with `unable to execute pager 'pager'` and prints nothing.
   Fix: `git config --global core.pager cat`.
3. **A fresh clone has no git identity.** `git commit` failed twice with *"Author identity
   unknown"* — but because other commands were chained after it, the error scrolled off and it
   read as a silent no-op. Two commits were believed made that were not.
   **Run `git commit` alone and read its output.** Identity now set globally
   (`Elliot Horton` / `etblues449@users.noreply.github.com`) so the replacement Fold inherits it.

## Code shipped — `e51cacf`

Correctness fixes to a tool that already worked. Four defects:

| Defect | Why it mattered | Fix |
|---|---|---|
| Counted `rows.length` under `limit=1000` | A 1001-row table would report **"1000"** — a fabricated number stated confidently. Breaks the honesty rule harder than any other bug here | PostgREST `Prefer: count=exact`, total read from `Content-Range`; when the server declines to count, it says so |
| **No write guard at all** | Nothing stopped a destructive phrasing reaching the endpoint | insert/update/delete/drop/truncate/grant/revoke refused **before** any network call |
| No timeout | Could hang indefinitely on a bad network | 8s `AbortController`; a hang is reported as a timeout |
| `'run'` tested twice; `'running'` matched it | *"how many agents are running"* returned **execution history** | Whole-word matching `\b(runs?\|executions?\|executed\|history)\b`; pinned by a regression test |

**Kept from the existing version:** the anon publishable key (safer in a repo than the service-role
key used in the scratch build), the tool contract, and its spoken phrasing.

**Discarded from the scratch build:** its `lib/config.mjs` was *worse* than the repo's existing
`lib/env.mjs` — it split on every `=` (mangling any value containing one) and clobbered real
environment variables. `lib/env.mjs` is canonical; nothing was added beside it.
