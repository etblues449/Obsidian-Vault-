## Architecture Notes

**JARVIS v1** is phone-native, Claude-powered, vault-centric:
- Classifier: Haiku (phone Claude)
- Storage: git vault (sync.sh auto-push)
- Secrets: plaintext .env (v1), Keystore wrapper ready (v2)
- Offline: Cloud only (v1); Ollama research (v2)
- HA control: REST (LAN v1), Tailscale (v2 roadmap)

**v2 Enhancements** layer on v1 without breaking changes:
- Keystore integration (fallback to .env)
- Network detection (auto-route offline)
- Wake word daemon (optional, parallel text input)
- Backup orchestration (independent, cron-driven)
- HA Assist bridge (v2.1, non-blocking)

**All v2 features degrade gracefully** — if Keystore unavailable, use .env; if Ollama down, use cloud Claude; if wake word fails, use text input.
