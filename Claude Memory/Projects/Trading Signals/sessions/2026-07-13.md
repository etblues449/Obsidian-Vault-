# Session 2026-07-13 — Vibe-Trading evaluation + auto-resolver

- Request: clone HKUDS/Vibe-Trading and see if it improves the Trade Guard artifact.
- Evaluation: Vibe-Trading is a full self-hosted agentic trading platform (Python 3.11 FastAPI backend, React 19 frontend, LLM-driven agent, Docker, ~20 market-data loaders, backtester, shadow/paper accounts, messaging-channel adapters incl. Telegram). Verdict: **not a replacement** — wrong tool class for a single-file, offline, phone-first verification console; it needs a server + LLM API keys, and its purpose (agent-driven strategy research/trading) is exactly what the funding gates exist to keep at arm's length until the channel is proven.
- **What was worth porting** (their loader-fallback chain + exit-reason adjudication):
  - `tools/resolve_trades.py` — keyless, stdlib-only adjudicator: Yahoo 15-minute gold bars first, Stooq daily CSV fallback; walks bars forward from each signal's timestamp; TP-first = win, SL-first = loss, one bar spanning both = **ambiguous** (left open for a manual call, never guessed). Unit-tested 8/8 (long/short × win/loss/ambiguous/open/no-TP).
  - Console import upgraded to apply resolutions: matching open trades auto-close at the adjudicated price with the real closedAt; ambiguous counted and surfaced; re-import idempotent. E2E-tested via Playwright (correct P&L: +$4 / −$9 on the sample; no JS errors).
  - This closes the biggest honesty gap: outcomes now come from recorded price history, not from anyone's memory of what "would have" happened.
- Artifact republished (same URL), vault copy + README + index updated, pushed to PR #60.
