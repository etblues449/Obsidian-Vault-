# Session 2026-06-29 — "Job" voice agent goes live

**Goal:** Recreate the TikTok concept — an AI you talk to that retrieves anything from the vault, with full context of every project. End state: a callable/tappable assistant wired directly to Obsidian.

**Outcome:** ✅ **LIVE** at `https://jarvis-voice-lovat.vercel.app` — a browser tap-to-talk voice agent that reads the vault from GitHub and answers out loud. $0/month, no phone number, built entirely from the Fold 7.

---

## What was built

A single-page voice agent ("Job"):

- **Front end** — static `index.html` on Vercel. One mic button. Uses the browser's **Web Speech API**: `webkitSpeechRecognition` for speech-to-text, `speechSynthesis` for text-to-speech. Button glows red (listening) → grey (thinking) → green (speaking). Conversation shows as chat bubbles.
- **Back end** — `api/voice-agent.js` (Vercel serverless). Accepts `{text}`, reads vault from GitHub via `@octokit/rest`, sends context + question to **Groq** (`llama-3.1-8b-instant`), returns `{reply, vault}`.
- **Vault read** — pulls `JARVIS/Inbox` (recent captures), `Claude Memory/MEMORY.md`, and today's session note, all from branch `master`.

Verified working: Job correctly described Smart Home (HA Green, ESP32 nodes, lounge/bedroom-2 status, BLE/UART contention), Faceless Finance (Wednesdays 4 PM), and Doc to Learning from the live vault.

## The pivot that made it free

Original plan was a **Twilio phone-callable agent**. Abandoned — UK numbers require a paid Regulatory Compliance bundle (since 30 Sep 2024), US numbers require a paid account upgrade. After deep research, switched to the **browser Web Speech API**: genuinely free forever, no phone number, no telephony provider, works in Chrome/Samsung Internet on the Fold 7. Tap-to-talk replaces the phone call.

LLM also swapped: **Claude Haiku → Groq Llama 3.1 8B**. Anthropic has no free-forever tier (only a one-time $5 credit); Groq's free tier is unlimited enough for personal use, no card required.

**Free stack:** Web Speech API (voice I/O) + Vercel Hobby (hosting) + Groq free tier (LLM) + GitHub API (vault read) = £0/month.

## Problems solved along the way (for future reference)

1. **Twilio UK regulatory bundle** — unavoidable paywall → pivoted to browser voice.
2. **GitHub PAT kept failing** — first token was auto-revoked (exposed in plaintext); later tokens lacked repo access. **Fine-grained tokens silently fail if the specific repo isn't granted at creation.** Final working token has access to `Obsidian-Vault-` with Contents read.
3. **Vercel deploys stuck at `UNKNOWN`** — the original `phone` project entered a broken state where new builds never completed (known Vercel issue). **Fix: deploy to a fresh project** (`jarvis-voice`) — a new project's first deploy always builds.
4. **404 on the deployed site** — caused by `"buildCommand":"npm install"` in `vercel.json`, which made Vercel expect a build-output dir. **Fix: remove buildCommand** so static `index.html` + `api/` serve correctly.
5. **302 redirect** — Vercel Deployment Protection (Vercel Authentication) was on, blocking public access. **Fix: disable it** in project settings.
6. **Deployment blocked — invalid commit email** — the repo's git history carried a fake `elliot@jarvis.local` author, which Vercel rejects. **Fix: `rm -rf .git`, re-init with the real GitHub email** (`ehorton@selectlifestyles.co.uk`).
7. **`vault:"unreachable"`** — two causes: (a) token couldn't read the vault repo, (b) code pointed at branch `claude/adoring-allen-LY2kF` but the vault's default branch is `master`. **Fix: working token + repoint to `master`.** Also made `fetchVaultContext()` fail gracefully so Job still talks even if the vault is unreachable.
