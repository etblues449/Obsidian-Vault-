# 📝 Quick Capture Templates

Use these templates when capturing to structure your notes. Copy the relevant template and paste into JARVIS Capture.

---

## 💼 Work Capture

```
[Your task/note here]

Context: [What's this related to?]
Priority: High/Medium/Low
Deadline: [Date if applicable]
```

---

## 💰 Finance Capture

```
[Expense/income/financial note]

Amount: $[amount]
Category: [Food/Transport/Tools/Savings/etc]
Date: [Today or specific date]
Recurring: Yes/No
```

---

## 🏃 Health Capture

```
[Health/fitness/wellness note]

Type: Sleep/Exercise/Nutrition/Mental/Other
Value: [e.g., 8 hours sleep, 5km run, mood 8/10]
Date: [Today]
Streak: [Day X of habit]
```

---

## 📚 Learning Capture

```
[Book note/course progress/skill learned]

Source: [Book/Course/Video/Mentor]
Topic: [What are you learning?]
Key takeaway: [One sentence]
Action: [How will you apply this?]
```

---

## 🎯 Goal/Project Capture

```
[Goal or project milestone]

Goal: [Name of the goal]
Progress: [X% or description]
Next step: [What's the next action?]
Timeline: [When should this be done?]
```

---

## 📋 Decision Capture

```
[Decision you're making]

Options: 
1. [Option A]
2. [Option B]
3. [Option C]

Decision: [What you chose]
Reasoning: [Why?]
Outcome: [Check back in 1 week/month]
```

---

## 🏠 Home/Personal Capture

```
[Personal note/idea/todo]

Category: [Home/Family/Social/Admin/Other]
Urgency: ASAP/This Week/This Month/Backlog
Who: [Does this involve anyone else?]
```

---

**Tip:** Type the template structure naturally into JARVIS Capture. Claude will extract and structure it automatically.
